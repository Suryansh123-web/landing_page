# DigitalOcean-Inspired Landing Page

A responsive, student-built cloud hosting landing page inspired by DigitalOcean for a college web development recruitment task.

> This is an educational recreation and is not an official DigitalOcean website. The pricing and plan details are illustrative.

## Features

- Semantic HTML structure
- Responsive layout for desktop, tablet, and mobile
- CSS Grid for feature and pricing cards
- Flexbox for navigation and CTA alignment
- Responsive hamburger menu with JavaScript
- CSS animations and hover effects
- Keyboard-visible focus states
- Reduced-motion preference support

## Project structure

```text
digitalocean-clone/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Resize the browser to test the responsive layout and mobile navigation.

No build tools or package installation are required.
